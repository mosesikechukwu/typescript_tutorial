# TypeScript Task List

A simple task list app built with TypeScript and Snowpack. Tasks are saved to localStorage so they persist across page refreshes.

## Live Demo

[https://mosesikechukwu.github.io/typescript_tutorial](https://mosesikechukwu.github.io/typescript_tutorial)

## Features

- Add tasks using the input form
- Mark tasks as completed using checkboxes
- Tasks persist in the browser via localStorage
- Built with TypeScript for type safety

## Getting Started

### Prerequisites

- Node.js installed on your machine
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/mosesikechukwu/typescript_tutorial.git
cd typescript_tutorial
```

Install dependencies:

```bash
npm install
```

### Available Scripts

#### `npm start`

Runs the app in development mode.
Open [https://mosesikechukwu.github.io/typescript_tutorial](https://mosesikechukwu.github.io/typescript_tutorial) to view it in the browser.

The page reloads automatically when you make edits.

#### `npm run build`

Builds a static copy of your site to the `build/` folder, ready for deployment.

#### `npm run deploy`

Builds the app and deploys it to the `gh-pages` branch on GitHub, making it available at the live demo URL above.

## How It Works

- Tasks are defined using a TypeScript `type` with `id`, `title`, `completed`, and `createdAt` fields
- Each task gets a unique ID generated by the `uuid` library
- Tasks are saved to `localStorage` as JSON whenever a task is added or a checkbox is toggled
- On page load, tasks are read from `localStorage` and rendered to the DOM
